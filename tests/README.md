# 검증 및 평가

검증 코드와 평가 시나리오를 관리합니다.

각 시나리오에는 입력, 기대 결과, 실제 결과와 확인 방법을 남깁니다.
민감정보 탐지와 위험도 분류를 구분해서 평가하고, 미탐·오탐 및 판단 근거를 기록합니다.

실행 가능한 테스트는 각 구현 폴더에 있습니다.

- 서버: `server/src/test` (`cd server && ./gradlew test`, 통합 테스트에는 Docker 필요)
- 화면: `web/src/**/*.test.*` (`cd web && npm test`)

대회 평가 문서의 정답표와 실행 결과는 대회 규정을 확인하기 전까지 이 저장소에 올리지 않습니다.
